P2P Chat

    Network settings

    Chat without a server

    Connect to someone by swapping a short code. Messages go directly between your browsers, encrypted, and are saved only on your devices.

    Connect to someone

    One person creates an invite and sends the code to the other (any messenger, email, …). The other person accepts it and sends a reply code back. No server is involved in the chat itself.

      P2P Chat is open in another tab.
      Only one tab can be connected at a time.
